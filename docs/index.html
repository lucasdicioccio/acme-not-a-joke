acme-not-a-joke

A Haskell library of primitives to perform ACME certifications (RFC 8555): the protocol by which a provider such as Let’s Encrypt issues TLS certificates.

The package is named acme-not-a-joke because acme- packages on Hackage typically are “joke” packages. This one is not.

import Acme.NotAJoke.Client
import Acme.NotAJoke.Api.Directory
import Acme.NotAJoke.KeyManagement
import Acme.NotAJoke.LetsEncrypt
import Data.Maybe

loadedjwk <- loadJWKFile "staging/key.jwk"
let jwk = fromJust loadedjwk
let contacts = ["mailto:certmaster@dicioccio.fr"]

leDir <- fetchDirectory (directory staging_letsencryptv2)
nonce0 <- fromJust <$> getNonce leDir.newNonce
postCreateAccount jwk leDir.newAccount nonce0 (createAccount contacts)

The library is incomplete and subject to changes, but the happy path works: create an account, place an order, answer a challenge, and fetch the certificate.

The code is on GitHub at lucasdicioccio/acme-not-a-joke.
